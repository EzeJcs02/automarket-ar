Base de datos

Estructura de datos

11 tablas en Supabase (PostgreSQL) con Row Level Security activo. Cada tabla tiene su propósito específico.

autos
Publicaciones de vehículos. Marca, modelo, año, precio, fotos, kilometraje, estado (activo/pausado), flags de boost (urgente, destacado, fijado_home) y fechas de vencimiento.
concesionarias
Agencias registradas. Nombre, responsable, ciudad, logo, portada, plan (free/básico/pro/premium), estado de aprobación y banner activo.
profesionales
Red de profesionales automotores. Categoría, datos de contacto, estado de aprobación, plan y visibilidad en la plataforma.
consultas
Leads entrantes de compradores. Auto, concesionaria, nombre, email, teléfono, mensaje, estado de lectura y fecha.
favoritos
Autos guardados por cada usuario particular. Relación user_id / auto_id con fecha de creación.
pagos
Historial de transacciones. ID de MercadoPago, tipo de pago, monto, estado, recurso afectado y fecha.
alertas_busqueda
Filtros guardados por usuarios. Email, filtros en JSON (marca, precio, año, km, etc.) y estado activo.
alertas_enviadas
Registro de qué autos ya fueron notificados por alerta. Evita emails duplicados en el cron diario.
publicidades
Banners de publicidad en Home. Imagen, link, fondo, estado activo — gestionados desde el panel admin.
guias
Contenido de las guías interactivas (compradores, vendedores, agencias, profesionales). Título y contenido en JSON.
arrepentimientos
Solicitudes de baja legal. Nombre, email, operación, monto, motivo, IP del solicitante y fecha límite de resolución (10 días hábiles).
Backend

Endpoints API

12 funciones serverless en Vercel, organizadas por responsabilidad.

Pagos
POST /api/mp-create-preference Crea checkout de MercadoPago (planes, boosts, publicaciones)
POST /api/mp-webhook Webhook de MercadoPago — verificación HMAC + actualización de BD
Emails y notificaciones
POST /api/send-consulta Envía consulta del comprador al vendedor (rate limit: 5/min)
POST /api/send-confirma Email de confirmación al comprador (valida auto_id en BD)
POST /api/welcome-email Email de bienvenida a nuevos usuarios (valida user_id en Supabase)
POST /api/notify-admin Notifica al admin cuando se registra una nueva agencia o profesional
Administración
POST /api/admin-actions Acciones de admin (aprobar, suspender, destacar) — requiere token + email admin
GET /api/admin-users Lista todos los usuarios de Supabase Auth — solo admin
Automatización (Cron jobs)
POST /api/cron-alertas 9 AM diario — envía alertas de búsqueda a usuarios registrados
POST /api/cron-expire-boosts 3 AM diario — vence boosts y publicaciones personales expiradas
Utilidades
GET /api/sitemap Genera XML sitemap dinámico para SEO con todos los autos y agencias
POST /api/arrepentimiento Registra solicitud de baja legal — Res. 424/2020

Seguridad

Medidas de seguridad

La plataforma implementa múltiples capas de seguridad tanto en el frontend como en el backend.

🔐
Autenticación API
  • Verificación de Bearer token en Supabase Auth
  • Whitelist de email para acceso admin
  • CRON_SECRET para proteger jobs automáticos
💳
Pagos seguros
  • Firma HMAC SHA256 en webhooks de MercadoPago
  • Protección anti-replay (ventana de 5 minutos)
  • Validación de montos server-side
  • Idempotencia por payment_id
🛡️
Validación de inputs
  • Regex de UUID para IDs (evita SQL injection)
  • Sanitización HTML (XSS prevention)
  • Límite de longitud en strings
  • Validación de email con regex
⚡
Rate limiting
  • 5 requests/min por IP en endpoints de email
  • 3 requests/min en arrepentimiento
  • Mapas en memoria por IP + timestamp
🌐
Headers HTTP
  • Content Security Policy (CSP)
  • CORS restringido a fioramarket.store
  • X-Content-Type-Options, HSTS
✅
Validación de propiedad
  • Verifica que el user_id existe antes de enviar emails
  • Verifica que auto_id existe antes de confirmaciones
  • Ownership check en pagos (user = dueño del recurso)
